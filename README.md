# Minimap Link

Phone page for a bike minimap on an ESP32-2424S012 (ESP32-C3, 1.28" round screen). Open it in the
Bluefy browser on iPhone (Safari has no Bluetooth), connect to `Minimap-xxxx`, and start a ride: it
sends your GPS position and the roads within 2.5 km to the board over Bluetooth LE.

Map data © OpenStreetMap contributors, under the Open Database Licence
(https://www.openstreetmap.org/copyright), fetched live from public Overpass API servers.
